# photos

Drop photographs in this folder and they appear on the website at the next deploy. Nothing else to do.

Three filenames are special, if you want them:

- `hero.jpg` — fills the screen behind "MAKE IT FIT."
- `anna.jpg` — the picture of Anna.
- `certificate.jpg` — the picture of the SITAM certificate.

Everything else goes into the "Made here" grid, newest names last. `.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. If the folder is empty the page shows tidy empty slots instead.

Only put up photographs you have permission to publish.
